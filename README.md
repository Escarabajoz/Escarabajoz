# 🚀 Featured Projects

## 🧩 IL2CPP-DirectX-ImGui

A **C++ DLL injection framework for Unity IL2CPP applications** featuring DirectX 11 hooking and ImGui integration.

### ✨ Highlights

- 🎯 DirectX 11 `Present` hook
- 🧬 IL2CPP runtime resolver
- 🔎 Class and method resolution
- 🧵 Thread management
- 🌐 Domain access
- 🎮 Unity API wrappers
- 🔍 Pattern / signature scanning
- 🎨 Custom ImGui components
- ✨ Animated UI elements
- 🛡️ Support for obfuscated Unity exports
- 🧠 RAII-based resource management
- 🧱 Modular project architecture

### 🧰 Built With

`C++` `DirectX 11` `ImGui` `IL2CPP` `Windows`

### 📁 Main Components

```text
IL2CPP-DirectX-ImGui
│
├── Cheat
│   ├── Functions
│   ├── Hooks
│   ├── Signatures
│   └── Utils
│
├── IL2CPPResolver
│   ├── Functions
│   ├── Unity
│   └── Utils
│
├── Utils
│   ├── Backend
│   ├── ImGui
│   └── Math
│
└── DllMain.cpp
```

🔗 **[View Repository](https://github.com/Escarabajoz/IL2CPP-DirectX-ImGui)**
